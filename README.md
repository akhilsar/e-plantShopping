# Paradise Nursery Shopping Application

## Overview
Paradise Nursery is an interactive shopping cart application built for an online plant shop. It offers a variety of house plants and provides a seamless, dynamic user experience from initial browsing to managing the shopping cart. 

## Key Features
* **Intuitive Navigation:** A persistent navigation bar that includes links to the landing page, product listing, and the shopping cart. It also features a dynamic cart icon that instantly updates to display the total quantity of items added.
* **Landing Page:** A welcoming entry point featuring a clear call-to-action button that seamlessly routes users directly to the main product catalog.
* **Categorized Product Catalog:** Plants are neatly organized into distinct sections (such as "Aromatic Plants" and "Medicinal Plants") for easy browsing.
* **Detailed Plant Cards:** Each plant is showcased using a dedicated card that displays its thumbnail image, name, description, unit cost, and an interactive "Add to Cart" button.
* **Dynamic Shopping Cart:** 
  * Displays a dedicated card for each type of plant added to the cart, showing the item's thumbnail, unit cost, and the calculated total cost for that specific plant type.
  * Includes interactive buttons to increase or decrease the quantity of each item, as well as a "Delete" button to remove the item entirely.
  * Automatically updates the overall total cost in real-time whenever a user modifies their item quantities.
* **Seamless Flow:** Includes "Continue Shopping" and "Checkout" buttons within the cart to guide the user's shopping journey.

## Technical Details
This project demonstrates the practical application of dynamic React functionalities. It effectively utilizes state management to handle complex user interactions, such as updating cart quantities across different components and calculating real-time pricing totals.
